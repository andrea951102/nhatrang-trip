## 2026-08-27 — food-list.csv 인코딩(UTF-8 BOM) 수정 + 맛집 5곳 카드 반영

**무엇을**:
- `docs/data/food-list.csv` 가 BOM 없는 UTF-8 이라 한글 엑셀에서 열면 깨지던 문제 수정 → UTF-8 BOM + CRLF 로 재저장. (커밋 `acbb418`)
- 사용자가 CSV에 구글맵 짧은 링크 5개 추가함. 각 링크 해석해서 식당명·카테고리·구글맵 평점·대표 사진 1장 추출, CSV 의 식당명/카테고리 칸 채움(코멘트·가격대는 빈칸 유지).
- `index.html` `#food-grid` 에 카드 5개 추가: **쳉안 딤섬**(딤섬, ★4.5) / **포한푹**(쌀국수, ★4.7) / **랑응온**(베트남 가정식·해산물, ★4.5) / **바 또이**(베트남 백반, ★4.5) / **하이산 타인 스엉 2**(해산물, ★4.4). 신규 카드는 갤러리 대신 단일 커버 이미지(`.food-cover`) 스타일.

**왜**: CSV 는 엑셀에서 편집하는데 BOM 없으면 한글이 CP949 로 오독됨. 앞으로 엑셀 저장 시 "CSV UTF-8" 포맷으로 저장하면 BOM 유지됨(task 문서에 명시).

**다음 할 일**:
1. 5곳 코멘트·가격대는 CSV 빈칸 상태 — 사용자가 채운 뒤 "반영해줘" 하면 카드 `.desc`/`.meta` 갱신.
2. 다중 사진 추출 방법 재확보 시(현재 og:image 1장만) 신규 카드도 갤러리로 승격. 배경은 [tasks/food-section.md](tasks/food-section.md) "사진 추출 메모" 참고.
3. 구글맵 사진(`lh3.googleusercontent.com/gps-cs-s/...`) 도 아고다와 같은 핫링크라 URL 만료 리스크 있음.
