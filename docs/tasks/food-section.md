# 맛집 섹션(#food) 진행 상황

## 워크플로우
1. [docs/data/food-list.csv](../data/food-list.csv)를 엑셀/구글시트에서 편집 (최대 10곳). 컬럼: `식당명, 카테고리, 구글맵링크, 코멘트, 가격대`
2. 엑셀에서 편집했다면 **"다른 이름으로 저장 → CSV UTF-8"**로 저장해서 같은 경로에 덮어쓰기 (일반 CSV로 저장하면 한글이 깨질 수 있음)
3. 저장만 해두면 자동으로 반영되지 않음 — Claude Code 세션에서 **"food-list.csv 반영해줘"**라고 명시적으로 요청할 것. (파일 변경이나 GitHub 커밋을 스스로 감지하는 기능 없음, 매번 직접 트리거해야 함)
4. 요청받으면: CSV의 각 행마다 구글맵 링크에서 사진 URL 추출 → `index.html`의 `#food-grid`에 카드 추가/갱신 → `GALLERIES` 객체에 사진 배열 추가 → 아래 체크리스트 갱신 → `docs/PROGRESS.md`에 로그 남기고 커밋

### 사진 추출 메모 (2026-08-27)
- 예전 방식(짧은 링크 curl → 내부 API에서 `geougc` 사진 다수 추출)은 이번에 재현 안 됨 — `/maps/preview/place`·`listentityphotos` 의 `pb` 파라미터 포맷이 바뀐 듯. 여러 변형 시도했으나 사진 배열 안 나옴.
- 대신 **Googlebot User-Agent 로 `maps/place/.../data=!4m2!3m1!1s{FTID}` 를 열면** `<meta property="og:image">` 에 대표 사진 1장이 안정적으로 나옴 (`lh3.googleusercontent.com/gps-cs-s/...`, `=w1000` 붙여 사용). 카테고리·주소·평점도 `/maps/preview/place` 의 최소 `pb` 로 여전히 추출됨.
- 그래서 신규 5곳은 갤러리(3썸네일) 대신 **단일 커버 이미지**(`.food-cover`, 클릭 시 구글맵)로 넣음. 나중에 다중 사진 방법 되찾으면 갤러리로 승격 가능.

## 참고
- CSV를 쓰는 이유: `.xlsx`는 읽으려면 매번 파이썬 패키지(pandas/openpyxl) 설치가 필요해 불안정함. CSV는 텍스트라 바로 읽힘.
- 매 대화창에 링크를 하나씩 붙여넣는 대신, 이 CSV 파일 하나로 모아서 관리하는 방식으로 전환함 (2026-08-19 결정, 최대 10곳 가정).
