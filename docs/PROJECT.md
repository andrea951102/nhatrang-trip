# PROJECT

## 목적
베트남 나트랑 여행(2026.12.18~12.26) 계획을 지인들에게 공유하는 인터랙티브 웹페이지. 항공권, 일정, 숙소, 리조트 후보를 한 페이지에서 보여주고 리조트는 아직 미정 상태로 같이 골라야 함.

## 배경
Notion 브리프(https://app.notion.com/p/Vietnam-Trip-Brief-3be8958aebc48006ac0ac5167fddb86c)로 시작한 여행 계획을, Claude Design으로 시각화된 단일 페이지 웹사이트로 만들어 GitHub Pages에 올림.

## 이해관계자
- 정상윤(사용자) — 계획 총괄, 리조트/숙소에 대한 의견을 페이지에 직접 반영
- 여행 동행 지인들 — 페이지를 보고 리조트 선택에 참여

## 범위 밖
- 예약/결제 기능 없음 (외부 아고다 링크로만 연결)
- 백엔드/DB 없음, 정적 페이지 하나로 완결
